Pengaturan Cloud Database

Status Koneksi Saat Ini: Local Storage

Secara default, aplikasi menyimpan data secara lokal di browser. Untuk menyalakan **Cloud Realtime Database** (agar data otomatis tersinkronisasi antar HP/laptop personil secara gratis):

Cara Membuat Database Firebase Gratis (2 Menit):
  1. Buka console.firebase.google.com lalu login akun Google.
  2. Klik Add Project / Buat Project Baru.
  3. Di menu samping, pilih Build > Firestore Database > klik Create Database (pilih Test Mode).
  4. Buka Project Settings (ikon roda gigi) > Scroll ke bawah klik ikon Web </>.
  5. Salin objek JSON const firebaseConfig = { ... }; dan tempel di bawah ini.
