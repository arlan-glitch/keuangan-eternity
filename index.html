Hubungkan Sync Realtime Semua Orang

Agar iuran & transaksi **langsung otomatis terupdate di HP seluruh anggota**, Anda perlu memasukkan **Firebase Config** gratis dari console.firebase.google.com.

📋 Cara Dapat Firebase Config (Gratis 2 Menit):

  1. Buka console.firebase.google.com & buat project baru.
  2. Pilih **Build > Firestore Database**, klik *Create Database* (pilih Mode Test/Public).
  3. Masuk ke **Project Settings** (ikon gerigi) > scroll ke **Your Apps** > pilih Ikon Web (</>).
  4. Copy bagian objek const firebaseConfig = { ... } lalu tempel (paste) di bawah.
